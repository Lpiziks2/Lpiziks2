## Hi, I'm Lauris

**Data scientist · MSc Business Data Science · Copenhagen**

I like work where data ends up guiding real decisions: getting messy data into a state you can trust, building models that are properly tested, and explaining the results so people outside data can act on them.

### What I work on

- **Data quality.** I prepare, check and validate messy data. I built a data validation pipeline that runs in production.
- **Reliable ML.** I build and validate machine learning models. My MSc thesis looked at how to spot when a model's confidence should not be trusted.
- **Communication.** I turn model output into dashboards and explanations that non-technical teams actually use.
